## Cómo evalúo una campaña de Meta Ads

**¿Qué pasa después de que alguien escribe por WhatsApp?** Para evaluar una campaña local, empiezo por distinguir tres momentos: la conversación que registra la plataforma, la cita que agenda el equipo y la atención que finalmente se concreta. Cada paso responde a una pregunta de negocio diferente.

| Pregunta | Qué reviso |
| :--- | :--- |
| ¿Qué presupuesto se utilizó? | Comparo gasto, calendario y cambios publicados para reconstruir qué configuración estaba vigente durante el período analizado. |
| ¿Qué ve la persona que recibe el anuncio? | Reviso si el título, la pieza gráfica y el mensaje de WhatsApp describen el mismo servicio. Compruebo también cómo se lee el texto en la pantalla de un teléfono. |
| ¿Qué resultado puede sostenerse con los datos? | Calculo el costo por conversación con los totales de gasto y mensajes. Para estimar el costo por atención necesito además las citas y asistencias atribuibles a la campaña. |

Con ese diagnóstico puedo proponer una prueba pequeña: cambiar una pieza, documentar la variante y comparar las consultas útiles y las citas durante un período acordado.
